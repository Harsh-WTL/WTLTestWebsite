Design language · September 2026

One product, one surface. Typography carries the hierarchy; colour only carries meaning.

Six font families, two token systems and 148 loose hex values become one set of primitives that Tailwind consumes directly. Written so that two engineers building two different tables land in the same place.

01
Density is a feature
An operator across 500 locations gets rows per screen. 44px comfortable by default, 36px compact one click away, remembered per table.
02
Colour is a signal
Interfaces are neutral. Green, amber and coral appear only where a state is true, and always alongside a word or a glyph.
03
Never lie about data
Empty, error, partial and stale are visually distinct from each other and from success. A dash is not a zero.
04
Quiet for eight hours
Soft canvas, near-white cards, one accent. Motion only where it reports progress — 120ms in, no bounce.

Geometric-humanist grotesque. Warm like the references, but with the aperture and x-height to stay legible at 13px in a 500-row table. Weights: 400, 500, 600 only.

03 — States
Five states, five silhouettes
A failed load must never resemble “nothing here yet”. Loading is a skeleton in the shape of the data; empty is centred and offers the next action; error is bordered in coral with a retry; partial keeps the rows it has and flags the gap; stale shows real data behind an amber ribbon.

Rollout, four PRs
01
Land tokens + aliases
New variables ship; old names become aliases. Nothing visually changes except the palette.
02
Fonts down to two
Drop four families from the loader; set Figtree on body, Geist Mono on the mono utility.
03
Table, tile, badge, chart
Four shared components replace the hand-rolled copies. This is where the 20 screens converge.
04
Delete inline styles + aliases
60 files lose their style={{}} blocks; the alias layer is removed last.
